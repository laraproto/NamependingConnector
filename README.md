# NamependingConnector

This is the connector plugin for Namepending, allowing sync to and from the panel, otherwise the panel is just kind of useless

## Features (and also the missing ones)

- [x] Ban sync
- [x] Warnings from in-game
- [x] Account linking
- [x] Group sync
- [x] Player sync, including stats
- [ ] Viewing Warnings or Bans command

## Building

This is an SDK style project so should be all and all pretty easy to build, you will need to set up an environment variable called SL_REFERENCES pointing to the dedicated server's managed folder or set up a ReferencePath.props.user file
